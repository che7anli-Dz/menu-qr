# Menu QR 🍽 — v1

منيو إلكتروني + QR + طلب واتساب للمطاعم والمقاهي والفاست فود والسناك والباتيسري والعصير.

> **قاعدة التسليم: ما يتنشر والو قبل ما يجربو Ismail الملف — لا GitHub ولا GitHub Pages. النشر غير كي يقول هو صراحةً من بعد التجربة.**

## الملفات

| الملف | واش فيه |
|---|---|
| `index.html` | التطبيق كامل (ملف واحد): لاندينج + تسجيل + لوحة تحكم + منيو عامة + سلة + طلب واتساب + QR الطاولات |
| `schema.sql` | جداول Supabase + RLS + دالة عدّاد المشاهدات — **يتنفذ مرة وحدة في SQL Editor، بإذن Ismail** |

## واش يخدم في v1

- **لاندينج:** «ودّع Menu الورقي!» + شعار «امسح، شوف، واطلب!» — الأسعار: 700 دج/شهر (الجزائر) / $9/شهر (الخليج)، الأوائل 20 سعرهم مثبت للأبد.
- **تسجيل صاحب مشروع:** Supabase Auth (إيميل + كلمة سر). إذا القاعدة مازالت ما تطبقش، التطبيق يخدم في **وضع تجريبي محلي** (localStorage) — باينة شارة «وضع تجريبي» في الهيدر.
- **لوحة التحكم:** إنشاء المشروع (اسم، slug، واتساب، واتساب المطبخ، فايسبوك، شعار، عملة) + أقسام + أطباق (اسم/وصف/سعر/إيموجي/صورة، تعديل وحذف وإخفاء) + إعدادات + QR + اشتراك.
- **المنيو العامة `?cafe=slug`:** أقسام + أطباق + سلة + أزرار تواصل (واتساب/اتصال/فايسبوك) + عدد المشاهدات.
- **زوج تدفقات الطلب:**
  1. **زبون في المحل:** QR الطاولة `?cafe=slug&table=2` → الطلب يوصل **واتساب المطبخ** مع رقم الطاولة («الطاولة 2: ...»).
  2. **زبون من الدار:** رابط الصفحة → يختار **توصيل** (اسم + تيليفون + عنوان) ولا **يجي يديها** (اسم + تيليفون) — بلا رقم طاولة.
- **QR الطاولات:** توليد أكواد لكل طاولة (1–50) + تحميل PNG لكل وحدة + طباعة الكل.
- **الاشتراك:** تجربة 14 يوم من التسجيل، من بعد تفعيل يدوي عبر واتساب (كيما حساب الحانوت). كي تخلص التجربة بلا تفعيل، المنيو يوري صفحة «اشتراك منتهي» بدل المنيو.
- **نوع المحل والخلفيات:** كل مشروع عندو «نوع المحل» (مطعم / مقهى / باتيسري / فاست فود / سناك / عصير — الافتراضي مطعم)، يتبدل من إنشاء المشروع ولا من الإعدادات. خلفية هيرو صفحة المنيو تتبدل حسب النوع (صور حقيقية فاتحة للشهية من Unsplash)؛ اللاندينج العامة عندها flat-lay محايد (طاولة خشبية). باقي التطبيق لون كريمي سادة باش صور الأطباق تبرز.
- **المطعم التجريبي:** «مطعم الديوان» (`?cafe=diwan`) — منيو مطعم حقيقي (أطباق رئيسية + مشروبات + حلويات، أسعار بالدج)، يخدم بلا تسجيل.
- **منيو بالصورة 📸:** «مقهى الديوان» (`?cafe=diwan-cafe`) — صاحب المحل يصوّر المنيو المكتوب برك؛ الزبون يشوف الصور ويكتب طلبو كنص حر، والطلب يوصل ديركت للمطبخ (بلا واتساب).

## منيو بالصورة 📸

لصاحب المحل اللي عندو منيو مكتوب وما يحبش يكتب 30–60 طبق يدوياً:

- **نوع المنيو** يتختار من إنشاء المشروع ولا من الإعدادات: «منيو مفصلة» (أطباق + أسعار + سلة — كيما قبل) ولا «منيو بالصورة» (تصوّر المنيو المكتوب برك — كاميرا ولا غاليري، الحد 6 صور).
- **الزبون** (منيو بالصورة): يشوف صور المنيو كمعرض (swipe + تكبير باللمس fullscreen) + جملة «الأسعار في الصورة»، ويكتب طلبو كنص حر في «اكتب طلبك هنا...» — الطلب يوصل **ديركت للمطبخ** كطلب عادي (بلا واتساب): مع رقم الطاولة إذا الرابط فيه `?table=N`، ولا الاسم + التيليفون + العنوان (توصيل) ولا «يجي يديها» إذا من الدار. الطاولة المسدودة ترفض الطلب كيما الطلب العادي.
- **التخزين:** عمود `menu_type` + عمود `photos jsonb` في `menu_cafes` (القسم 14 في `schema.sql`) + صور في Supabase Storage bucket اسمو `menu-photos` (قراءة عامة، كتابة غير للمالك — يتنشأ من Supabase Dashboard → Storage). التطبيق يرفع لـ `menu-photos/<cafe_id>/<uid>.jpg` ويحفظ الروابط العامة في `menu_cafes.photos`. في **الوضع التجريبي المحلي** الصور تتحفظ base64 في localStorage (ديمو برك).
- **الديمو الثاني:** «مقهى الديوان» (`?cafe=diwan-cafe`) — نوع مقهى، منيو بالصورة (صورة لوحة منيو حقيقية من Unsplash). «مطعم الديوان» يبقى منيو مفصلة.

## التشغيل محلياً (للتجربة)

```bash
cd ~/workspace/your_files/menu-qr
python3 -m http.server 8123
# افتح: http://localhost:8123/
# المنيو التجريبي: http://localhost:8123/?cafe=diwan
# منيو بالصورة: http://localhost:8123/?cafe=diwan-cafe
# طاولة 2: http://localhost:8123/?cafe=diwan&table=2
```

الإنترنت لازم (Supabase + QRCode.js + خط Cairo من CDN). بلا إنترنت، المكتبات ما تتحملش.

## تفعيل Supabase (كي يأذن Ismail)

1. افتح Supabase → SQL Editor → نفذ `schema.sql` كامل (مرة وحدة).
2. افتح التطبيق — إذا الجداول موجودين، الشارة «وضع تجريبي» تختفي ويولي التخزين في Supabase.
3. جرّب: سجّل حساب → أنشئ مشروع → زيد أقسام وأطباق → افتح `?cafe=slug` في تيليفون آخر → اطلب → رسالة واتساب توصل.

**ما تطلبش كلمة سر القاعدة وما تطبقهاش بلا إذن Ismail** — هي استعمال واحد.

## الأمان

- RLS على كل الجداول: القراءة عامة للمنيو، الكتابة غير لمالك المشروع (`auth.uid() = owner_id`).
- في `index.html` كاين غير المفتاح العمومي (publishable) — **ما كاش service key وما كاش كلمة سر** في الكود.
- كل نصوص المستخدم تتعرض بـ `esc()` (حماية XSS)؛ الأسعار أرقام برك (`parseFloat` + `check (price >= 0)` في القاعدة).
- عدّاد المشاهدات بدالة `SECURITY DEFINER` تزيد +1 برك — الزائر ما يقدرش يبدّل أي حاجة أخرى.

## خلفيات الإطارات حسب الكلمة (frameBg)

كل بطاقة/إطار ياخذ صورة خلفية داخلية حسب موضوعو (الكلمة) — فوقها طبقة بيضاء خفيفة (.62→.70) باش الكتبة تقرا مليح. اللي ما يتطابقش ياخذ صورة نوع المحل (أو flat-lay في اللاندينج).

| الكلمات | الصورة (Unsplash، متحقق منها 200) |
|---|---|
| طاولة / طلب / واتساب / طباعة / كيفاش | طاولة مطعم — `photo-1517248135467-4c7edcad34c4` |
| طبق / أطباق / منيو / بيتزا / برغر | أطباق — `photo-1546069901-ba9599a7e63c` |
| مشروب / قهوة / عصير | مشروبات — `photo-1544145945-f90425340c7e` |
| حلو / حلويات / باتيسري / كيك | حلويات — `photo-1551024506-0bccd828d307` |
| سعر / أسعار / اشتراك | flat-lay محايد — `photo-1504674900247-0877df9cc836` |

تتطبق على: بطاقات أقسام المنيو (حسب اسم القسم)، أقسام اللاندينج + البطاقات اللي داخلها (حسب العنوان)، وخلايا QR الطاولات. خلفية الصفحة (صورة النوع) تبقى تبان من الجوانب ومن بين البطاقات (veil خفيف .45/.55 + إطار زجاجي أشف).
